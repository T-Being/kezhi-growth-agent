# 正式交付物

这里只保存产品正式产出。PDF 用于阅读，Word/PPT 用于后续编辑；同一内容的不同格式不是两个独立版本。发布副本保留交付时正文及版式；Office 文件仅清理作者和最后修改者属性，其余内部成员逐字节核对一致，当前工程能力以根目录 README、源码和验证记录为准。

| 主题 | 阅读版 | 可编辑版 | 范围 |
| --- | --- | --- | --- |
| 产品方案 | [PDF](product-overview.pdf) | [PPT](product-overview.pptx) | 11 页图文产品方案，包含演示入口与目标体验 |
| 商用评测 | [PDF](evaluation-plan.pdf) | [Word](evaluation-plan.docx) | 23 页评测设计；数值是候选门槛，未附实测成绩 |
| 经营模式推广 | [PDF](business-model-expansion.pdf) | [Word](business-model-expansion.docx) | 目标、反馈、策略与成熟复盘的模式适配 |

产品演示稿中的概念界面与当前可运行应用存在差异；不可用演示稿画面判定代码已实现全部能力。旧的阶段名称及阈值以当前[准入说明](../docs/evaluation/release-gates.md)和独立评测方案为准，界面以当前源码为准。

[manifest.json](manifest.json) 记录文件大小和 SHA-256 校验值，用于确认正式发布文件未被误替换。更新正式版本时同时更新索引、哈希、关联文字文档及变更记录。
