# 分阶段准入标准

本表结构化整理自[商用评测方案第 20 节](../../deliverables/evaluation-plan.pdf)。工程组织规范和原型测试通过，不代表已经达到任何真实商用阶段。

| 阶段 | 证据要求 | 可开放范围 | 当前状态 |
| --- | --- | --- | --- |
| G0 影子试点 | 核心链路、数据口径、服务端隔离和授权通过，严重缺陷清零 | 少量授权用户只读评估 | 待验证 |
| G1 受控付费试点 | 建议质量、适用模块、安全集和试点负载通过 | 限定客户、平台和策略，人工审核登记 | 待验证 |
| G2 正式辅助商用 A0 | 业务非劣、护栏、净效率、单位经济和 14 天稳定观测 | 批准范围的付费建议服务 | 待验证 |
| G3 逐次确认执行 A1 | A1 安全测试，不少于 300 个沙箱异常场景及 100 次授权灰度动作 | 审批、额度和白名单内的具体动作 | 未实现、未验收 |
| G4 受限自动执行 A2 | 累计额度、并发、撤权、停止、补偿及完整经营周期灰度 | 验收过的客户、动作、额度及期限 | 未实现、未验收 |

## 建议冻结的量化门槛

| 判断 | 候选标准 |
| --- | --- |
| 建议质量 | 合格率 ≥90%，95% 下限 ≥85%；无实质修改率 ≥85%，95% 下限 ≥80% |
| 辅助商用业务非劣 | 主指标相对改善 95% 下限 >−3%，同时通过护栏 |
| 对外宣称投放增益 | 改善点估计 ≥5%，95% 下限 >0，同时通过护栏 |
| 业务护栏示例 | 转化量相对差 95% 下限 >−5%；退款率差 95% 上限 <1 个百分点 |
| 净效率 | 总人时下降点估计 ≥30%，95% 下限 >0；P90 不高于基线 |
| 单位经济 | 连续两个成熟结算周期整体客户净价值为正、供应方贡献毛利率 ≥50% |
| 安全红线 | 跨客户泄漏、误写、越权、重复执行和未确认经验生效均为 0 |

这些是原方案候选门槛，需由业务、产品、数据、质量和技术负责人在试点前结合基线冻结。置信区间跨界、样本不足、结果未成熟或功能未实现均不得记为通过。

## 决策与证据包

结论使用“通过、限范围通过、待验证、未通过”。说明版本、平台、客户类型、动作白名单、权限期限及允许对外表述的价值。不用附加条件绕过尚未修复的安全缺陷。

证据包包括输入快照、模型与检索配置、独立任务清单、原始输出、盲评分歧、分子分母、失败用例、业务试验、人时和经济记录、稳定性及恢复演练。各角色签署自己负责的判断，产品负责人批准最终范围。

回滚时保存审计与真实动作记录。关闭模型或恢复前端版本不会撤销已发生的广告平台动作，必须回读并按授权处理。
