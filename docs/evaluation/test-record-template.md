# 验收记录模板

本文件为后续真实评测使用的空白模板，当前没有填写任何业务通过结论。

## 单用例

| 字段 | 待填写内容 |
| --- | --- |
| 标识 | 用例 ID、模块、业务目标、版本、执行时间与人员 |
| 范围 | 客户类型、平台、P/L/A 级别、账户授权 |
| 输入 | 数据与记忆快照、任务请求、依赖、允许动作集合 |
| 步骤与预期 | 操作顺序、对象、参数、状态、证据及禁止行为 |
| 实际输出 | 原始建议、截图、日志、平台回执、人工修改 |
| 量化结果 | 各维评分、分子分母、时延、人时、成本与人工兜底 |
| 结论 | 通过／未通过／待验证／不适用，并说明证据 |
| 缺陷与复测 | 严重度、影响、负责人、修复版本、复测证据 |

## 模块与发布

登记独立任务数、通过数、95% 区间、关键切片、红线失败、基线差异和未覆盖能力。发布决议另附业务效应、数据成熟状态、非劣和护栏、人时与单位经济、未关闭缺陷、回滚负责人、开放范围和复审条件。

失败输出保留原样；复测作为新记录关联原缺陷，不能覆盖初次失败。未开放写权限时，不填写真实执行成功率。

依据：[正式评测方案第 22 节](../../deliverables/evaluation-plan.pdf)。
