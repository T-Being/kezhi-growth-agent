# 五分钟演示指南

启动后打开 http://127.0.0.1:4173 。所有数据及动作均为模拟，无需登录，不会修改真实投放。已有操作可从左下角「运行设置」重置。

## 主流程

1. 在工作台点击「处理 ROI 异常」，查看青禾家居趋势、计划及预算限制。
2. 点击「分析原因」，展开数据证据和客户记忆，体验三个预设追问。
3. 生成调整方案，将 B 预算改为 500 元，观察总预算超限后无法继续；再恢复推荐值。
4. 保存草稿后刷新，核对进度恢复。进入执行预览，查看账户和各计划前后值。
5. 勾选确认后返回修改预算，再进入预览，验证之前的确认已经失效。
6. 恢复推荐值，重新核对、勾选并执行，观察每项动作状态。
7. 进入复盘，加载预置未来观察数据；核对因果限制后确认经验回写。
8. 切换山野户外，检查该客户记忆与青禾家居独立。这里验证的是页面数据归属，不是服务端租户安全。

## 异常分支

| 运行设置 | 应观察到 |
| --- | --- |
| 部分成功 | 查询当前配置，再确认重试未完成动作 |
| 状态未知 | 不显示已成功，不直接再次提交；先查询 |
| 全部失败 | 显示失败，核对后可确认重试 |
| 配置变化 | 原确认失效，返回方案重新处理 |
| 数据不完整 | 限制生成方案，补齐数据后恢复 |
| 预算授权过期 | 阻止执行预览，复核关键记忆 |

也可以浏览客户中心、任务优先级、记忆来源、历史复盘、操作记录和交接摘要。右下角信息助手基于规则和本地数据提供查询入口，不是自由生成的 AI 助手。

## 演示口径

“执行成功”只表示模拟配置完成；演示复盘的 ROI 变化不能作为增长证据。当前版本只在青禾家居提供完整主链路，其余客户用于经营资料与协作浏览。商业效果及生产级权限仍需按[评测方案](../evaluation/strategy.md)验证。
