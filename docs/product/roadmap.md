# 产品演进路线

以下为基于现有产品方案和代码补充的实施建议，不是交付承诺。阶段以退出证据推进，不预填日期或负责人。

| 阶段 | 工作内容 | 退出条件 |
| --- | --- | --- |
| 当前原型 | 客户工作区、固定诊断、预算确认、模拟恢复、复盘回写 | 工程测试与完整演示流程通过 |
| 真实只读基础 | 登录与租户授权、广告数据同步、业务口径、持久化记忆和审计 | 访问隔离、数据质量和来源追踪验证通过 |
| AI 辅助建议 | 客户范围内检索、事实与假设分离、证据引用、结构化建议与拒答 | 锁定评测集通过，质量及记忆增量价值有证据 |
| A0 试点与商用 | 优化师审核、人工执行登记、真实复盘、成本与人时记录 | 业务非劣、净效率、单位经济及稳定性达标 |
| A1 确认执行 | 服务端预检、版本绑定、幂等、回读与部分失败恢复 | 沙箱和限定真实动作验收通过 |
| 模式扩展与 A2 | 经营适配模板、成熟反馈、额度与撤权控制 | 按模式和动作独立准入，具备人工接管 |

## 已知差距

- 模拟客户状态在同一个浏览器存储中，不能用于保存真实客户资料。
- 关键授权校验目前读取状态字段，日期是固定业务快照；尚未按实际时钟自动过期，也没有验证缺失授权记录的生产级完整性。
- 诊断、建议和助手使用本地逻辑，没有大模型或检索服务。
- 真实执行的身份、幂等、版本一致性、审计和补偿尚未实现。
- 真实效果、性能容量、商业价值、跨模式适配都处于待验证状态。

进入真实客户试点前，先补齐上述基础能力，再使用[准入标准](../evaluation/release-gates.md)判断范围。
